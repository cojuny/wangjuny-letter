# 💗 왕주니의 고백 페이지

**화이트 메인 + 연핑크 포인트**의 작은 고백 웹사이트입니다. PC와 모바일에서 이용할 수 있습니다.

## 사용 방법

1. ZIP을 압축 해제하세요.
2. `index.html`을 더블클릭해 브라우저에서 여세요. (인터넷 불필요)
3. **NO** 버튼은 PC에서 마우스가 가까워지거나 휴대폰에서 터치하면 **화면 반대편까지 멀리 도망갑니다.** 버튼은 화면 밖으로 나가지 않으며 YES는 계속 누를 수 있습니다.
4. **YES** 버튼을 누르면 같은 폴더의 `yes.html`로 이동하며 하트가 나타납니다.
5. YES 화면에는 **복사·공유·붙여넣기 기능이 없습니다.** 직접 만나서 보여주시면 됩니다.

**중요:** `index.html`, `yes.html`, `styles.css`, `script.js` 네 파일은 같은 폴더에 있어야 합니다.

## 직접 문구 수정하기

- 고백 멘트: `index.html`의 `mainTitle`, `description` 부분
- 승낙 화면 멘트: `yes.html`의 `successTitle`, `success-description`, `promise-card` 부분
- 색상: `styles.css` 상단의 `--pink`, `--pink-deep`, `--pink-soft`
- NO 버튼 멘트: `script.js`의 `lines`

일반 HTML, CSS, JavaScript로 제작되어 설치나 빌드가 필요하지 않습니다. 외부 이미지나 라이브러리 호출도 없습니다.
